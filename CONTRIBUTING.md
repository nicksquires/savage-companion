# Contributing

This is currently a **solo portfolio project**, so I’m not accepting pull requests yet.

However, **issues and feature requests are very welcome** — especially if you’re a Savage Worlds player and spot something that should work differently in the rules engine, the Edge Browser, or any of the seeded data.

Feel free to open an issue for:
- Bugs
- Rules clarifications
- Feature ideas
- Feedback on the current `/reference/edges` experience

Thank you for your interest in the project!
